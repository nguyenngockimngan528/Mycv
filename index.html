HTML · CSS · JavaScript cơ bản

Xây dựng trang web giới thiệu và trưng bày các sản phẩm vật dụng, phụ kiện và thức ăn cho chó mèo với bố cục rõ ràng, dễ sử dụng.

  • Thiết kế trang chủ, danh mục thức ăn & vật dụng thú cưng (vòng cổ, đồ chơi, chuồng, hạt dinh dưỡng).
  • Áp dụng CSS cơ bản (color, background, font-family, margin, padding, border, border-radius, box-shadow, display) để trình bày thẻ sản phẩm.
  • Tích hợp thao tác lọc danh mục và thêm sản phẩm vào giỏ hàng minh họa bằng JavaScript cơ bản.
